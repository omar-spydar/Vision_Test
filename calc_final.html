$$ \text{px/cell} = \frac{\theta \cdot (\text{width}_{px}/\text{HFOV})}{N} $$
$$ \theta = 2\,\arctan\!\left(\frac{W}{2d}\right) $$
θ ≈ –°
Alternate (lens mode - future calc)
$$ \text{px/cell} = \frac{W\cdot w}{d\cdot s}\cdot\frac{f}{N} $$
θ = tag angular width (degrees)
W = tag physical width (meters)
d = camera-to-tag distance (meters)
width_px = image width in pixels
HFOV = horizontal field of view (degrees)
N = marker dictionary size + 2 (for black border)
f = focal length (mm)
s = sensor width (mm)

Heuristics for recommendations
  • > 10 px/cell (best): 7×7 viable; 6×6 rock‑solid.
  • 8–10 px/cell: 6×6 solid; 7×7 often OK.
  • 6–8 px/cell (work): 5×5–6×6 workable.
  • 4–6 px/cell: prefer 4×4; 5×5 borderline.
  • < 4 px/cell: increase res / narrow FOV / move closer.
